# Start a conversation via client chats

Use TaxDome's Client Chats feature for real-time messaging to schedule appointments and request documents. Here, find out how to create new chat threads and initiate reminders.

## Create a new chat thread

A chat thread can be created by a firm owner, an admin, or a team member assigned to the account or with a view all accounts access rights.

### Start a thread with one client

**Web**

There are different ways to manually create a new chat thread with one client:

- Go to **Communications > Chat** or to **Clients > Accounts > Communication > Chat** and click **New chat**.
- Click the **New** button at the top left, select **Chat**, complete the form and click **Create chat**.

**Mobile**

You can create new chat threads either from the **Inbox** screen or by navigating to the **Accounts** > Select an account > **Chats**.

### New Chat screen overview

Below are sections in the **New Chat** screen where you create a new thread:

**a. Template:** Choose a template for frequently sent messages. When selected, the **Subject** and **Message** fields fill automatically. Templates can only be selected when creating new chats, not when responding.

**b. From:** Team member on whose behalf the message will be sent. Default is the sender, but you can choose another team member.

**c. Thread assignee:** Select who will be automatically assigned to manage this conversation. This determines responsibility for following up on client responses. Team members must have account access to be assigned to threads.

**d. To:** Select the name of the person the message is for.

**e. Subject:** Enter the subject displayed in the **Chat** list. Click **Add shortcode** to individualize the subject with dynamic data like client name or date.

**f. Message:** Compose the message using text formatting, emojis, bullets, numbered lists, and links. Use @ before a team member's name for attention, or click **Attach** to add documents from your desktop or TaxDome.

**g. Link to jobs:** Select jobs to link, then click **Save**.

**h. Reminders:** Toggle on for reminder emails when clients don't respond within a time frame or don't complete tasks.

**i. Tasks:** Add checklists for your clients.

**j. Create chat:** Click to send your message to the client. Otherwise, click **Cancel**.

### Start threads with several clients

If you need to send the same message to many clients, use the bulk messaging feature.

1. Go to **Clients > Accounts** from the left sidebar menu.
2. Select the checkboxes next to the clients you want to message.
3. Click **More actions** in the top menu bar, then click **Send message**.
4. Select a chat template or write a subject (optional), add your text and tasks if needed. Documents cannot be added in bulk messages but can be sent individually afterward.
5. Click **Create chats**.

You can also create chat threads in bulk the same way as for one client—just add more recipients.

When creating chats in bulk, you can assign threads to a team member. If the assignee lacks access to some accounts, those threads remain unassigned.

> **Note:** You can create a chat thread with clients who haven't activated their TaxDome account yet. Email notifications go to contacts with emails. Upon portal activation, they can read previously sent chat messages.

## Set up chat reminders

Reminders are automatic follow-up emails nudging clients who haven't replied to a chat message or completed action items in the thread.

**Web**

To turn them on, toggle on **Reminders** when creating a chat, then set:

- **Days until next reminder** — how often the reminder repeats (default: 3)
- **Number of reminders** — how many reminders to send total (default: 1)

The reminder schedule appears in the chat thread for both you and the client, showing what action stops the reminders.

To update or turn off reminders later, open the chat thread, click the bell icon, and adjust the **Send reminders to clients** toggle.

**Mobile**

Reminders can only be set up in the web portal, but you can see if they're active for a chat in the mobile app. When enabled, a bell icon appears next to the chat name—tap it to view the schedule and remaining reminders.

> **Tip:** See more on reminders—exact field defaults, stop conditions, and the menu action for each manual resend.

## Client view

If notifications for the client are on, they are informed about new messages or when new chat threads are created. Your clients can see and open chat messages in different ways:

- **From the client portal or mobile app:** Click the notification under the **Home** page in the **To-do list** or directly from the **Chats** page.
- **From the email notification:** Click **View chat** in the email. By default, the message content is not displayed in the email notification body. However, if the content is not sensitive, you can show it in the email.

> **Note:** If clients reply to the notification email instead of in a chat thread, the message isn't delivered and they receive an error email. If they wonder why their thread reply wasn't received, this might be the reason.

Your clients can interact with your chat thread from their portal: answer, mark tasks as done, upload documents, and create new chats (if allowed).

> **Tip:** You can see the sent message from the client's perspective.
