# How do I generate an extension for a 1040 return using worksheet view

The video below shows how to create a 1040 extension and where to enter adjustments and overrides using CCH Axcess™ Tax, CCH® Global fx Tax, and CCH® ProSystem fx® Tax.

There are two methods for creating extensions in a return.

- Method 1: Generating an Automatic Extension.
- Method 2: Entering information to fill out the extension.

## Method 1: Generating an Automatic Extension - [Return]

With this method, the system uses information already present in the return to generate the Form 4868 and amounts.

1. Go to **General > Return Options**.
2. Select **Section 2 - Form Printing Options**.
3. In **Line 15 - Form 4868 (automatic extension of time to file)**, use the drop-down to select **Mandatory extension**.
4. In **Line 16 - State Extension (resident state automatic extension of time to file)**, use the drop-down to select **Mandatory extension** (if applicable).
5. Calculate the return.

## Method 2: Entering information to fill out the extension - [Return]

With this method, you designate the amounts that flow to the Form 4868.

1. Go to **Extensions > Extensions**.
2. Select **Section 1 - Automatic Extension (Form 4868)**.
3. In **Lines 1-13 - General Information**, enter information as applicable.
4. In **Lines 14-15 - Letters and Filing Instructions**, enter information as applicable.
5. In **Lines 17-22 - Federal column**, enter information as applicable.
6. In **Lines 17-23 - State column**, enter information as applicable.
   - **Note:** Click **Add** at the top of the state column to add additional states.
7. Calculate the return.
