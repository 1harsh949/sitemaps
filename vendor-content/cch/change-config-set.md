# How do I change the Return Configuration Set for returns in CCH Axcess Tax

## Objectives

Change the Return Configuration Set (RCS) associated with one or more returns.

## Environment

- CCH Axcess™
- CCH Axcess™ Tax

## Procedure

For one return, do the following:

1. Open Return Manager.
2. Locate the return on screen.
3. In the Return Configuration column drop down, select the down arrow to show a list of all Return Configuration Sets.
4. Select the desired Return Configuration Setup.
   - If the desired RCS is not listed, it can be searched for via the "Filter List" box.

For multiple returns, do the following:

1. Open Return Manager.
2. Select the corresponding checkbox for each return needing to be updated.
3. Select **Manage** on the toolbar.
4. Select **Update** from the dropdown menu.
5. On the Update Tax Return screen, select the Return Configuration Set from the dropdown menu.
6. Select **Continue**.
7. Select **Apply Changes**.
