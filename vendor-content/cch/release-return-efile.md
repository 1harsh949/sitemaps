# How do I release a return to the tax authority for electronic filing

If you selected Upload and Release to Tax Authority when exporting the return to Electronic Filing from Tax, the return was sent to the taxing authority at that time. You do not need to follow the steps in this article to release the return.

If you selected Upload and Hold when exporting the return to Electronic Filing, then you still need to release the return or extension to the tax authority. To release the return or extension to the tax authority, do the following:

1. Open Electronic Filing Status.
2. Click the **Release Return(s)** tab.
3. Use the Filter or Search section to find the return or extension that you want to electronically file.
4. Select the returns that you want to release.
5. Click **Release to Taxing Authorities**.
6. Verify the released returns are correct, and click **OK**.

## Notes

- If you see "No match found" after releasing a return, click the **e-filing Status** tab and use the Filter or Search sections to search for the return you just released. The status of the return or extension will be "Released for Transmission."
- Once the return is transmitted, it has been sent to the taxing authorities and cannot be stopped. If changes to that return are necessary, the return must be amended or superseded. When you release a return, the return is transmitted within seconds.

## Warning!

- Only one return or extension per client ID, tax year, and return type can be in "Ready to Release" status on the Release Returns tab.
- If you selected "Upload and hold" when exporting the return, do not upload another return or extension for that client ID unless you intend to replace it with the new upload, or unless you have already released the previous upload to the tax authorities.
