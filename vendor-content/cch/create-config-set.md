# How do I create a new return configuration set in CCH Axcess Tax

Return configuration sets are used to create setup options in Tax, such as signature block, correspondence options, and e-filing options.

To create a return configuration set, do the following:

1. Open Dashboard.
2. Click Configuration on the navigation panel.
3. Click Return configuration sets under Tax.
4. Click New on the button bar.
5. Enter a name and description for the return configuration set and click OK.
6. Enter all the applicable information for the options listed on the navigation panel under your new return configuration set.
7. Click Save & Close.
