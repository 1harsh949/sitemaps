# How do I configure CCH ProSystem fx Tax to use interview forms or worksheet view

You can configure the default input method in Office Manager or Tax Preparation. Office Manager configuration sets the input method for all staff in your firm. The input method set in Tax Preparation applies to the user log in ID.

## Office Manager (Office Group level)

1. Open Office Manager.
2. Click **Configure Firm > Input Methods**.
3. In the "Data input methods" section, choose from the following:
   - **Enable both Interview forms and Worksheets as data input methods** - Staff can select the preferred input method.
   - **Enable Interview forms only** - Staff can use Interview forms only for data input.
   - **Enable Worksheets only** - Staff can use Worksheets only for data input.
4. If both interview forms and worksheets are enabled, in the "Input default" section, choose from the following:
   - **Default to Worksheets when first opening Tax Preparation** - When Tax Preparation opens, the default view is Worksheet View.
   - **Default to Interview forms when first opening Tax Preparation** - When Tax Preparation opens, the default view is Interview Form View.
5. Click **OK**.

## Tax Preparation (User level)

1. Open Tax Preparation.
2. Close the "Open Return" window.
3. Click **View**.
   - Select **Worksheet** or **Interview**.
   - **Note:** To switch between Worksheet View and Interview Form View, both views must be enabled in the Office Manager setting.
4. If **Worksheet** is selected, you can select from the following View menu options:
   - **Worksheet Menu/Tree** - Worksheet groups are listed on a gold bar across the top of the Tax Preparation window. You can navigate to worksheet sections and forms in a navigation panel on the left side of your window.
   - **Full Window Worksheet List** - Worksheet groups, sections, and forms are organized in a list format. This view typically eases the transition from Interview Form View to Worksheet View. This view is similar to the worksheet organization in CCH Axcess Tax.
5. If **Interview** is selected, you can select from the following View menu options:
   - **Split Windows Forms Tree** - Use a form navigation panel on the left side of your screen to browse to all input and government forms. Forms are organized in a tree view.
   - **Full Windows Forms Tree** - Input and government forms are listed on a single and separate window. Forms are organized in a tree view similar to the Split Windows Forms Tree view.
   - **Full Windows Forms List** - Input and government forms are listed in a single and separate window. Forms are organized in a list view.
