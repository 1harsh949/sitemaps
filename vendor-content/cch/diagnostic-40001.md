# Diagnostic 40001 - return disqualified from electronic filing (1040)

Diagnostic: 40001 - "This return has been disqualified from electronic filing for the following reason(s):" for a 1040 return in CCH Axcess™ Tax or CCH® ProSystem fx® Tax.

## Full Diagnostic Text

"Electronic Filing. This return has been disqualified from electronic filing for the following reason(s):"

## Resolution

This diagnostic is a generic diagnostic that issues when another level 4 electronic filing diagnostic is present. To clear this diagnostic, review the diagnostics that begin with a 4 (such as 40001). Once all level 4 diagnostics are cleared, the 40001 diagnostic will also clear.

- For more information, see our solution on Reviewing, clearing, and signing off on diagnostics in CCH Axcess™ Tax and CCH® ProSystem fx® Tax.

If this diagnostic is issuing and no other level 4 diagnostic are present in the return, open a support case or chat with a representative for further assistance.
