# How do I use worksheet view in CCH Axcess Tax

Worksheet view allows you to enter tax return data in worksheets and government forms. Data entered in worksheets is transferred to the appropriate government form upon calculation of the return.

More information about using worksheet view in CCH Axcess Tax can be found here.

The main topics covered are:

- Navigation and display controls
- Using navigation history
- Links to worksheets
- Worksheet grids
- Multiple occurring sections
- Detail worksheets
