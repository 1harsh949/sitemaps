# How do I check a return or extension status on the Electronic Filing Status site

How do I check a return or extension status on the Electronic Filing Status site for CCH Axcess™ Tax or CCH® ProSystem fx® Tax?

1. Open Electronic Filing Status.
2. Click the e-filing Status tab.
3. Select the filter options that you want to use.
   - **Tax Year.** The tax year of the return or extension that you want to check.
   - **Return Type.** The type of return or extension that was e-filed. If you aren't sure what type of return or extension it is, select **All**.
   - **Preparer.** The preparer assigned to the return or extension. We recommend selecting All.
   - **Status.** The status of the return or extensions that you want to search for. We recommend selecting All.
   - **Office.** If your firm uses multiple account numbers, select the account number you want to use.
   - **Date From** and **Date To**. The date range the returns or extensions were filed on. We recommend leaving these boxes blank.
   - **Office Groups.** Select the office group that the return or extension is assigned to. We recommend selecting All.
   - **Federal**, **State**, or **FBAR**. Select any or all of the check boxes for the entity that was e-filed.
   - **Exclude Returns On Extension.** Select the check box if you if you do not want to see extensions in the results list.
   - **Show Returns with Signature Forms Not Received.** Select the check box if you only want to see returns that you have received the signature forms back from your clients.
4. Click **Go**. The search results appear in the bottom half of the page.
5. Locate the return or extension in the list. The Federal Status and State Status columns show the status of the return or extension.
   - Click the return ID for additional details.
6. If a return or extension is rejected, click **Rejected**. A rejection report appears that explains why the return or extension was rejected. The rejection report also explain how to clear the rejection. After you have edited the return or extension using these instructions, recalculate it, and re-export it to electronic filing.

## Notes

- Accessing Electronic Filing Status when using ProSystem fx Tax will only show returns electronically filed using these programs.
- Accessing Electronic Filing Status when using CCH Axcess will only show returns electronically filed using CCH Axcess Tax.
- If you have followed the steps above and the return is not listed, do the following:
  - Re-export and upload the return again. If the initial upload was successful, the second upload will override this initial upload.
