# Enter apportionment data for state returns

Follow these steps to enter apportionment data by state for a return.

## Steps

1. Select **View**, then **Apportionment**.

   > Note: You need to have a state return attached to the current client to open this window.

2. Select the **Property**, **Payroll**, or **Sales** tab and enter information in the Apportionment spreadsheet for the selected factor.

   > Note: Some fields in the Apportionment spreadsheet and state tabs have statement windows to enter detailed information for this factor's component. UltraTax CS uses the information entered in the Everywhere column in the statement window as the everywhere amount for that component. UltraTax CS ignores the amount in the Everywhere/(Override) column in the Apportionment spreadsheet for that component.

3. If the state needs more information that you cannot enter into the spreadsheet (including city and other return apportionment information), use the state tab. If the state doesn't need more information, no state tab appears in this window.

4. Repeat steps 2 and 3 to complete the data entry for the remaining factors.

## Tips

- Use the detail asset data entry to classify assets for the property factor and automatically transfer the end-of-year amounts to the corresponding fields in the property factor spreadsheet.

- You can use the Excel Export/Import tool to import all spreadsheet information at once.

- You can import data from an Excel spreadsheet or the Windows Clipboard into a statement window.

- By default, the cursor moves to the next row in a column when you complete a field. When you switch to Cursor Right mode, the cursor moves to the next column in the same row. To switch, select **Movement**, then **Cursor Right**.

- To delete data from the spreadsheet, select the data and then use the DELETE key, select **Cut** in the toolbar, or select **Edit**, then **Cut**.

- To select an entire spreadsheet column, select the column heading.

- To select an entire spreadsheet row, select the component heading at the beginning of the row.

- To select the entire spreadsheet, select the main component heading of the spreadsheet.

- You can override the amount in the Everywhere/(Override) column for all states or on a state-by-state basis.
