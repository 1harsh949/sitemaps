# UltraTax CS data-entry windows overview

To begin entering data for a client in the input screens, select the **Open Client** icon. As you enter data, UltraTax CS calculates amounts for the relevant forms, which display when you switch to form view.

- Use the **Tax Subject Index** to determine where to enter specific data.
- By default, when you open a client, the 1st input screen opens (if the client is new) or the last input screen in which data was entered opens.
- To customize how, when, and where UltraTax CS screens and forms display, select **Window**, then **Display Settings**.

## Input screen view: the folders block and input screens

The main data-entry window contains two sections:

- **Folders block**: Offers quick access to input screens based on the client's entity type.
- **Input screens**: Windows where you enter client data, grouped into folders by category.

Visual cues in the folders block:

- Horizontal lines on folder icons indicate that data exists in that folder.
- Double-folder icons indicate that multiple sets of input screens are available.
- Asset data can be entered in input screens or in the asset module.

If you're processing a state return for a client, you can use the application buttons in the folders block to switch between the federal and state input screens.

## Form view: the folders block and forms

Form view displays information similarly, with the folders block providing access to the forms that will print with the return. Form Navigation buttons illustrate the transfer of information through the return.

- To view a list of all forms, regardless of whether the form is required for the current return, right-click the folders block and select **Display All Forms**.
- Overridden values display as red, italicized text.

## Switch between input screens and forms

Use any of these methods to switch between input screens and forms:

- Select the **Form** icon or the **Input Screen** icon.
- Select **Form** or **Input Screen** from the **View** menu.
- Press **Ctrl+F** (Form view) or **Ctrl+I** (Input Screen view).
- Press **Ctrl** plus the **\*** key on the numeric keypad.
- Select the form or input screen links in the data entry sections.
- Enable Form/Input Screen Linking in form view to view both simultaneously (especially useful with multiple monitors).
