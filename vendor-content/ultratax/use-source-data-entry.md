# Use UltraTax CS Source Data Entry

Source Data Entry (SDE) allows you to input information from client source documents like W-2 forms and export that data to the client's tax return in UltraTax CS. Once entered, you can share the data with UltraTax/1040 client returns via the Data Sharing feature.

## Steps to Use Source Data Entry

1. **Open the application** from either the desktop icon or within UltraTax CS by navigating to **Utilities** > **UltraTax CS Source Data Entry**
2. **Select the form** you need to complete from the available options
3. **Enter data** from your source document into the form fields using dropdown menus or by typing as appropriate
4. **Review for accuracy**, then select **Export to UltraTax CS**
   - **Alternative actions:** Select **Postpone** to exit without exporting, or **Discard** to delete entered data and close
5. **Repeat steps 2-3** for any additional forms needed for that client
6. **Open UltraTax CS** and access the client's return
7. **Review the Data Sharing window** that appears with pending updates
8. **Accept, retain existing, or postpone** the import as needed
9. **Verify amounts** for accuracy and select **Done**

## Important Notes

Data imported from SDE displays in blue within the client's tax return. To review what was imported, navigate to **Utilities** > **Data Sharing** > **Imported Fields Listing**.
