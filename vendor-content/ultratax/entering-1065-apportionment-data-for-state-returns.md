# Enter 1065 apportionment data for state returns

Use this procedure to enter apportionment data by state for the client.

The detail level you enter must support the most complex apportionment form attached to the client. Some summary apportionment forms require information for only a few components (for example, the Ohio Form 4708 schedule), while more complex apportionment forms require many components (for example, Kentucky Form 765, Schedule A). Organize the client's apportionment information by state before entering data.

## Apportionment data categories

On 1065 state apportionment forms, data divides into two categories:

- **In-state amount:** The factor amount for a specific component for that state, including only amounts applicable to that state.
- **Everywhere amount:** The total apportionment amount for a specific component, including both in-state and out-of-state amounts.

## Procedure

1. Make sure a state return is attached to the current client.
2. Select **View**, then **Apportionment**.
3. Select the **Property**, **Payroll**, or **Sales** tab.
4. Enter information in the Apportionment Information spreadsheet.
5. If the state requires additional information that isn't available in the spreadsheet, use the state tab at the bottom.
6. Repeat for the remaining factors or states.

## Tips

- UltraTax CS uses the white fields and the **Everywhere / (Override)** column to complete the state forms.
- Amounts in shaded fields accumulate in the **Everywhere / (Override)** column.
- Use the Excel Export/Import utility to import or export apportionment information.
- Override the **Everywhere / (Override)** column amount on a state-by-state basis if necessary.
