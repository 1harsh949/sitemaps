# General electronic filing information

The following resources contain general information and supplemental documentation pertaining to 1065 partnership electronic filing:

- **1065 MeF Introductory Information Page** - IRS resource page with useful information regarding 1065 e-file for both novice and veteran EROs.
- **Filing Information For Tax Pros & Partners** - General resource page on the IRS website dedicated to 1065 e-filing.
- **Publication 4163** - Contains general information about the 1065 Partnership MeF program for the current tax year.
- **Valid XML Schemas and Business Rules for 1065 / 1065-B Modernized e-File (MeF)** - Contains links to current valid schemas, or e-file standards, published by the IRS. Select the appropriate links to view the release memo, schemas, or business rules.
- **MeF Status Page** - Provides a range of Modernized e-file (MeF) statistics and provides alerts about processing problems that affect the MeF system.
- **Electronic Federal Tax Payment System (EFTPS)** - EFTPS allows taxpayers to establish an electronic payment method for federal tax payments, which is necessary if a corporate taxpayer wants to establish electronic payments for estimated tax.
- **Partnership FAQs** - IRS answers to frequently asked questions regarding 1065 e-filing.
- **Recommended Names and Descriptions for PDF Files attached to Modernized e-File (MeF) Business Submissions** - Provides information on IRS recommendations for EROs to use certain PDF file names and descriptions to ensure prompt processing.
