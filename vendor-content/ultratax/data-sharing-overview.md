# Data sharing overview

You can use the data sharing features of UltraTax CS to share basic client data between UltraTax CS, other CS Professional Suite applications, and Onvio. Use data sharing to enter client information in 1 application and send it to other applications to save time and avoid mismatched client information.

## Types of information shared

- Client demographic information such as names, addresses, and phone numbers between UltraTax CS, Accounting CS, Practice CS, and Onvio.
- K1 financial data between UltraTax CS 1040, 1120, 1065 and 1041 clients.
- W-2, 1099-R, 1099-MISC, 1099-INT, and 1095-C financial data between UltraTax CS 1040 and Accounting CS.
- Client notes between UltraTax CS, Practice CS, FileCabinet CS, and Fixed Assets CS.

## Data sharing with CS Professional Suite applications

By default, data sharing with CS Professional Suite is turned on and the process is automatic once you've set up the file locations. File locations tell each application where to find data for the applications in the suite.

- Set up the file locations in each application.
- Enter the SSN or EIN in a client.
- Enter the rest of the client information in the return.
- Select **Preview**, then close the preview and the client.

When you open a return, UltraTax checks the data in other clients with the same SSN or EIN, and tells you if there's any differences. You can accept, discard, or postpone the data changes.

## Data sharing settings

You can take any of the following steps to change the way UltraTax CS applies data sharing.

- Prevent UltraTax CS from showing the Data Sharing window when you open a client.
- Change a client's participation in data sharing.
- Turn off data sharing for all UltraTax CS clients.

## Data sharing with Onvio

UltraTax CS shares demographic client information to Onvio using Onvio Link. Enter the data locations specified in each application, then go to **Settings** in **Onvio Link** and turn on data sharing.

Onvio Link uses 9-digit EIN/SSNs (such as those on K1s, 1099s, and W-2s) to create contacts in the Onvio Client Center. UltraTax CS only shares the following information.

- Addresses
- Emails
- Phone numbers
