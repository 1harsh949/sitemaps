# Select the state return to process

You can add state returns for a client at any time.

After you add a state return for a client, a button with the state's name appears in the folder list in tax data entry. Select the state's button to enter data for a state return. Use the buttons to switch between federal and state returns.

Some states require both part-year and full-year resident returns to appear on the same forms. Some have resident and nonresident returns on the same forms. Other states have separate forms for residents, nonresidents, and part-year residents. UltraTax CS provides you with the necessary forms for the states you select in **File**, **Client Properties**.

When you enter data in federal input screens and statement windows, the 1st time you enter a state ZIP Code, UltraTax CS asks you if you want to add that state to your client (if you haven't already done so). You're prompted only once for each state.

> **Important:** When you proforma data for a client with a multiple-state return in the previous year, the application automatically includes the states in the folders block for that client if the state application is present, or automatically includes the state the 1st time you open the client after installing the state application. Note that if one or more of the states no longer applies, select **File**, then **Client Properties** to remove the state.

---

**Applies to:**

- Product: UltraTax CS
- Return type: 1040 Individual
