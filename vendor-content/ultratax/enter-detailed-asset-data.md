# Enter detailed asset data

The Asset module is the default way to enter asset depreciation and amortization information for returns.

> To turn off the Asset module and use input screens instead, go to **File** > **Client Properties** > **Advanced Properties** > **Enter Asset Detail** tab and clear the **Enter asset detail information** checkbox.

## Workflow

* Open the **Asset List** window for an activity.

  > Any assets you've already entered for this activity appear in the asset list. The default columns are Asset #, Description, In Service (date), Disposal Method, Tax Cost/Basis, Tax Current Depr, and Group. You can customize column settings.

* In the **Asset List** window, you can:
  * Select **Add** to add an asset. This opens a new record in the **Asset Detail** window.
  * Select an asset, then **Modify** to change an existing asset. This opens the asset's record in the **Asset Detail** window.
  * Select an asset, then **Delete** to delete an existing asset.

* When you select **Add** or **Modify**, the **Asset Detail** window opens. Use the fields and tabs to enter or change asset information.

* When you finish entering data for the asset, do one of the following:
  * Select the Add asset button on the toolbar (or use CTRL+A) to save and move to the next record
  * Select Done to save and return to the **Asset List** window
  * Select any input screen tab to return to tax data entry

  > UltraTax CS automatically calculates and transfers asset data to the tax forms.

* Select **Tasks** > **Display Calculation** when the **Asset Detail** window is open to view depreciation calculations.

## Automatic Calculations and Transfers

After you enter asset information, UltraTax CS:

* Calculates depreciation for each asset
* Transfers depreciation totals to business activities
* Transfers tax preference amounts to appropriate forms
* Transfers asset sale information to Form 4797
* Transfers asset like-kind exchange information to Form 8824
* Transfers home office information to Form 8829 and/or Home Office Worksheet
* Transfers casualty/theft information to Form 4684
* Transfers asset depreciation and vehicle information to Form 4562, Auto Worksheet, or Form 2106
* Prints individual Form 4562 for each business activity when needed
* Prints detail reports for federal, state, AMT, and ACE amounts
* Prints detail report showing AMT and ACE adjustments
