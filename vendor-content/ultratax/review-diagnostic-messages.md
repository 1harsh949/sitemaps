# Review diagnostic messages

UltraTax CS provides helpful messages to alert you about incorrect data or missing information needed for your tax return.

## Accessing Diagnostic Messages

You can view diagnostic messages through any of these methods:

- Select the **Diagnostics** icon
- Select **View**, then **Diagnostics**
- Use CTRL+D

A window will open displaying different tabs organized by message type. You can keep this window open while working, resize it, move it between monitors, or close it using the close button at the top.

Selecting any message takes you directly to the relevant section of the return. UltraTax CS updates diagnostic messages continuously as you add or modify data.

## Diagnostics Window Tabs

**Critical**
Messages about missing data or significant issues that could affect the return. Address these before filing.

**ELF Critical**
Messages required to clear before electronic filing. Only appears when filing electronically.

**Overrides**
Lists any preset values you've changed, with details about what has been overridden. Only displays if overrides exist.

**FYI**
Important items that may not require action. Right-click and select "Acknowledge" to move items to the acknowledged list. Manage which FYI messages display via Setup > Office Configuration > Diagnostics.

**Forms Approval**
Shows forms not yet officially approved by tax authorities. Only appears when such forms are in your return.

**Tickmarks**
Tracks forms and input screens with fields marked with a tick, showing changes since marking.

**Watch**
Displays important return numbers to monitor. Freeze the tab to highlight changes in red. Add or remove fields to customize.

**To Do**
Lists incomplete items and tasks. Right-click items to acknowledge or edit.

**Complexity**
Shows your client's tax situation complexity score. Enable via Setup > User Preferences > Misc tab, then mark "Display the Client Complexity factor."

**Input Screen Overrules**
Lists overridden amounts on input screens, with unacknowledged items listed first.
