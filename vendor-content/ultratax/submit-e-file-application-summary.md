# Submit e-file application summary

To file returns electronically via UltraTax CS, you'll need to submit a copy of your IRS e-file application summary. If you attempt to e-file without verifying your e-file application summary, you will receive the following message:

> "Your CS Connect electronic filing capability is disabled. Thomson Reuters requires preparers to submit a copy of their 'Application Summary' from E-Services prior to e-filing. Please send the application summary to EFINCertificate@thomsonreuters.com and include your firm ID (1234) in the subject line."

## Steps to Access and Submit Your IRS E-file Application Summary

1. Visit the IRS website and select **Tax Pros**.
2. Select **Access e-Services** in the e-Services section.
3. Go to the e-Services Applications section and select **E-file Provider Services**.
4. In the e-file Application section, select the **Access e-file Application** button to open the e-Services sign-in page.
5. Enter your credentials to sign in to the IRS e-Services site. You'll also need to perform multi-factor authentication by entering a security code sent to your phone.
6. On the Select Organization page, mark the checkbox next to your firm's name and select **Submit Selected Organization**.
7. On the ESAM Application Landing Page, in the View/Edit select the icon for the e-file application.
8. On the application summary page, select **Print**.
9. Create a PDF of your e-file application summary by selecting Adobe PDF as the printer, then select **Print**. (This step varies depending on your browser.)

   > **Note:** If uncertain about creating an e-Services portal or needing assistance with sign-in errors, contact the IRS e-Help desk at **866-255-0654**.

10. Send your e-file application summary to EFINCertificate@TR.com, and include your firm ID number in the subject line.
    - If you have more than one EFIN number for your account, send an IRS e-file application summary for each EFIN.
11. Send a single message to EFINCertificate@tr.com and indicate in the body of the message the firms IDs for each office location that will be using the EFIN associated with the attached e-file application.
