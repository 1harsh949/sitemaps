# Install UltraTax CS

Review the installation considerations before you begin installing. You'll also need to download the installer.

1. Go to the folder you saved the installer to.
2. Right-click **UTDownload_YYYY.exe**, where YYYY is the year you're installing.
3. Select **Properties** and, if it exists, make sure the **Unblock** checkbox is marked. This lets your antivirus know it isn't malicious.
4. Select **Apply** and **OK**.
5. Right-click **UTDownload_YYYY.exe** again.
6. Choose **Run as Administrator**.

   When the installation begins, wait for the files to extract. If the installer doesn't start, there's likely a permissions issue. Try using the Hidden Administrator account to run the installation.
7. Select **Next** to begin the installation. You must read and accept the license agreement to proceed with the installation.
8. Verify and/or enter the information in the UltraTax CS Product Selection window.

   - **Installing to** is where the program will install. Make sure this path is correct.
   - Enter your Firm ID and PIN in **Licensing information**. If you don't know your PIN, see [Managing your license PIN](/en-us/help/ultratax-cs/get-started/install-and-update/manage-your-license-pin.html).
   - Select **Install products**. We recommend you choose **Install available licensed UltraTax CS products**.
   - We recommend you select **Install UltraTax CS Product Group licenses**. If you don't have your licenses or you want to skip the license installation, leave it unchecked. This will install the program without entities, but you can add those later.
   - We recommend you select **Add desktop shortcut icons**.
9. Select **Install**. The rest of the installation process is automatic.
10. Select **Finish** to close the installer.

If you're installing on a network, you'll need to run a desktop setup on each workstation that will access UltraTax CS. Terminal server installations should have a desktop icon after you install, but if it doesn't, run a desktop setup on the Terminal server. If you aren't remoting into the server to use UltraTax CS, run the desktop setup on each workstation.
