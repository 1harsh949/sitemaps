# Proforma client data from the previous year

If you used UltraTax CS last year, you can proforma (roll over) client data into this year's application. You can also proforma client data converted from another tax application.

Do the following to proforma client data from the previous year.

- Select **Utilities**, then **Proforma**.
- Make sure the **To data location** field has the correct location.
- Select **Clients**.
- Use the **Focus** section to filter the list of clients.
- Select the clients you want to proforma.
- Verify that the drive and path of last year's data are correct. If not, you'll need to specify the correct location.
- Select **Proforma**.

  A Proforma status window will open to show the progress.

- Select **Done**.
