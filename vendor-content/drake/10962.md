# The Drake Tax Planner

The Drake Tax Planner helps you assist clients in planning for the future by comparing their current tax situation to different scenarios—such as marriage, birth of a child, buying or selling a house, or income changes—to see how these changes may affect finances and tax liability.

## Key Information

**Availability:**
- Tax planning scenarios are available for 1040, 1120, 1120-S, and 1065 returns (1040 only in Drake Tax 2022 and prior)
- Not available for state returns

**Getting Started:**
Open a client's return and click the Tax Planner icon to open the Tax Planner dialog box. The original return and any created scenarios appear in a list.

## Toolbar Button Functions

- **New** - Create a new scenario for 2025 or 2026. Select tax year, enter scenario name, and click OK
- **Open** - Select a scenario and click Open to access it as a return
- **Remove** - Select a scenario and click Remove to delete it
- **Compare** - Select up to three scenarios and click Compare to compare them to the original return
- **Help** - Get explanations and directions for using the planner
- **Exit** - Close the planner and return to regular Drake Tax data entry

## Scenarios

Each scenario behaves like a normal return, except:
- The main data entry menu displays "Tax Planner"
- Documents in View/Print mode display a Tax Planner watermark (except letters)

**Caution:** Tax Planner scenarios do not update year to year.

## Depreciation

The Tax Planner does not consider the current year's depreciation when calculating depreciation in the next year scenario. The basis used in the current year return is also used for the next year's scenario. In the Tax Planner next year scenario, prior depreciation can be adjusted on screen 4562 to include the current year depreciation amount.
