# Drake Tax - PDF Attachments - Attachments for e-File

## Overview

When e-filing a return, you may need to include a PDF attachment. Two types of attachments exist:

**Software Attachments**
- Identified by the software based on your data entry
- Not generated on the PDF data entry screen
- Generates red EF Message to prevent e-filing until completed
- Can be eliminated by completing the attachment or removing the condition requiring it
- Most state return attachments are software attachments

**Preparer Attachments**
- Identified at your discretion on the PDF screen
- Can be signature documents, third-party documents, or columnar format information
- All PDF screen entries are preparer attachments to federal returns only
- Cannot be attached to state returns unless the state has a separate PDF attachment screen
- You can attach multiple PDFs for the same form name if each has a unique name

## PDF Name Requirements

- Must contain only alphanumeric characters; no punctuation or special characters allowed
- Should be 50 or fewer characters
- Do not use single quotes, double quotes, angle brackets, ampersands, or exclamation points
- Use only single spaces between words or numbers
- Cannot have two PDF attachments with identical file names for the same return; at least one character must differ

**Valid example:** "Form 8949 1.pdf"

**Invalid examples:**
- Form 8949_1.pdf
- Form 8949  1.pdf (two consecutive spaces)
- Form 8949-1.pdf
- Form 8499(1).pdf

## Clearing Messages

**To clear a software attachment message:**
- Attach the required document, OR
- Modify data entry to avoid requiring the attachment, OR
- Use a Paper Document Indicator (PDI) if available on Individual returns (this removes the document from the PDF attachment screen)

**To clear a preparer attachment message:**
- EF Message 6300 (Individual)/1511 (Business): Enter missing information on the PDF screen
- EF Message 5950 (Individual)/1510 (Business): Enter ".pdf" file extension in the File Name field on the PDF screen
  - **Caution:** The file must be an actual PDF document; adding the extension to a non-PDF file results in IRS reject X0000-029
- EF Message 5952 (Individual)/1512 (Business): Complete the attachment process
- Remove your entry on the PDF screen

Messages clear after recalculating the return.

## Preparer Attachment Process

1. Return to data entry and open the PDF screen
2. Enter the Reference Source, Description, and File Name
3. The File Name must end with ".pdf" extension and exactly match the PDF document filename (case-sensitive)
4. Exit the screen
5. View the EF PDF page to confirm the preparer attachment is now listed

## Creating the Attachment

- Must be a PDF file (do not rename non-PDF files with .pdf extension)
- If multiple pages, must be scanned or printed to a single multi-page PDF file
- Can merge existing PDFs using Drake Documents
- Should be scanned or printed to a location you can find when attaching (client's folder in Drake Documents is recommended, or desktop)
- If password protected, you must know the password

## Attaching the PDF

1. View the return; a red Messages page displays indicating attachment is required
2. Click the Attach PDF button on the toolbar to open the EF PDF Attachments dialog box
3. Select the first document and click Browse
4. Navigate to the document location, select it, and click Open
5. Confirm the check mark appears in the EF PDF Attachments dialog box
6. Repeat for remaining attachments
7. When all attachments show check marks, the process is complete; associated messages clear after recalculation

## Reviewing PDF Attachment

In View/Print mode, click the Attach PDF button on the toolbar. A green check mark indicates the document is attached. Click View to open the attachment.

**Note:** A voluntary attachment listed on an EF PDF page indicates it was entered on the PDF screen in data entry, not that attachment was completed.

## Removing an Attachment

The Delete button on the EF PDF Attachments dialog box removes the file, but red messages will direct you to complete the attachment.

To remove an attached file and eliminate red messages:
- If listed on the PDF screen in data entry (preparer attachment): Remove the entry to eliminate red messages
- If a software attachment: Modify data entry so the attachment is no longer necessary

## Updating an Attachment

1. Go to View/Print mode
2. Click the Attach PDF button to open the EF PDF Attachments dialog box
3. Select the attachment and click Delete (displays an "X" next to it)
4. Recalculate the return
5. Return to the EF PDF Attachments dialog box
6. Select the attachment and click Browse
7. Navigate to the updated document and attach it
8. Confirm a check mark appears next to the attachment
9. Click View to confirm it is the updated document
10. Recalculate the return to clear the EF Message

## 990 / 990-EZ / 990-PF / 990-N (Exempt Organizations)

- Use the PDF screen under the 990 tab
- By default, attachments link to Form 990, 990-EZ, 990-PF, or 990-N
- To attach to Form 990-T or Form 4720, select the form from the Attached to Form drop list
