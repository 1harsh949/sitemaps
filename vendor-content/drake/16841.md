# Drake Tax - 1040: Generating an Amended Return

**Caution:** Note that 2022 and prior regular or amended returns can no longer be e-filed. Only 2023, 2024, and 2025 forms are eligible for e-file.

A 1040-X is used to correct previously-filed Forms 1040 and 1040-SR. Some 1040-X forms for a 1040-NR may be e-filed.

The 1040-X displays both original return values and corrected "amended" values. To populate original return values, you can either enter them directly on the X screen or auto-fill them from an original return created in Drake Tax. Corrected values flow to the 1040-X after making necessary corrections in data entry.

## Before Beginning

- Read the 1040-X instructions and state amended return instructions (if amending a state return)
- If the return exists in Drake Tax, archive or back it up to avoid losing previously-entered data

## Understanding the 1040-X Columns

- **Column A. Original Amount:** Original return data as filed
- **Column B. Net Change:** Calculated difference between columns A and C
- **Column C. Correct Amount:** Corrected (amended) data

**Important:** See Drake Tax - 1040-X: FAQs and Troubleshooting for FAQs, Notes, Common Issues, and Rejects.

## Amending a Federal Return That You Originally Prepared in Drake Tax

1. Open the original return you want to amend
2. Before making corrections, open the X screen and click Yes to auto-fill original values (these appear in Column A)
3. Complete necessary fields on the lower half of the X screen
4. Go to View/Print mode and review the 1040-X to identify where changes should be made
5. Correct the original return in data entry, then return to View/Print mode to confirm results
6. Verify that both Form 1040-X and the entire Form 1040 showing in view mode are correct. Form 1040 along with all schedules, forms, and PDFs that are generated or attached are transmitted with Form 1040-X
7. Handle payment or refund scenarios:
   - If additional tax liability exists, complete the PMT screen with the applicable 1040-X box marked. If e-filed but payment sent by mail, Form 1040-V will be produced
   - If filing Form 9465 (Installment Agreement Request), mark the checkbox "Installment Agreement is for balance due on 1040-X"
   - For refund scenarios, see Drake Tax - 1040-X: FAQs and Troubleshooting
   - Late filing penalties, late payment penalties, and interest are not calculated for Form 1040-X
8. Go to the EF screen and check the box for 1040-X to indicate e-filing. If preparing a state amended return, select it in the drop list; otherwise click Do NOT send any states
9. Go to the PIN screen and ensure:
   - The applicable 1040-X box is selected
   - The PIN signature date reflects when Form 1040-X was completed
   - Taxpayers' PIN signatures are entered before transmission
10. Calculate the return to verify a green check mark for Form 1040-X
11. Exit the return and go to EF > Select Returns for EF, choose the return, and click Continue
12. Go to EF > Transmit/Receive, verify the selection, and click Send/Receive
13. The 1040-X will receive a pending ack, followed by either an accepted or rejected ack, just like other returns

## Amending a Federal Return That You Did NOT Originally Prepare

1. Create a return for the taxpayer, completing the name and address screen and entering basic information
2. Open screen X and enter amounts from the original, incorrect 1040. Drake Tax recommends this simplified approach to save you time that would be otherwise spent attempting to produce incorrect calculations
3. Use familiar data entry screens to prepare the complete corrected return
4. Calculate and review the return in View/Print mode
5. Verify that both Form 1040-X and the entire Form 1040 shown in view mode are correct
6. Handle payment or refund scenarios (same as section above)
7. Go to the EF screen and check the box for 1040-X. If preparing a state amended return, select it; otherwise click Do NOT send any states
8. Go to the PIN screen and ensure:
   - The applicable 1040-X box is selected
   - The PIN signature date reflects when Form 1040-X was completed
   - Taxpayers' PIN signatures are entered
9. Calculate the return to verify a green check mark for Form 1040-X
10. Exit the return and go to EF > Select Returns for EF, choose the return, and click Continue
11. Go to EF > Transmit/Receive, verify the selection, and click Send/Receive
12. Return to EF > Transmit/Receive > Acks only to pick up the IRS ack

## Amending Both a State and Federal Return

State amended returns vary. If there is a state X screen requiring original state data and the original state return exists in Drake, start by auto-filling the state X screen before modifying data entry on federal or state screens. Complete the federal amended return, then return to complete the state X screen and make needed corrections.

Only certain state amended returns are eligible for e-filing.

---

## Amend a Previously Amended Return (Second or Third Amendment)

**If the previously-amended return exists in Drake Tax:**

- Archive or back it up before proceeding
- Open and delete the X screen
- Treat the previously-amended return as your original
- Proceed with ordinary amendment steps above
- On the EF screen, select which amended return number this is:
  - 1040-X - 2nd amended return
  - 1040-X - 3rd amended return

**If neither the previously-amended return nor the 1040-X exist in Drake Tax:**

- Create the amended return or create a basic return by entering demographics
- Proceed with ordinary amendment steps above
