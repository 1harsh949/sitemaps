# Drake Tax - Data Entry Basics

## Red and Green Field Backgrounds

A red-shaded field indicates "a detail worksheet has been created for that line item." Double-click the field or press CTRL + W to open the worksheet. Each worksheet requires a title, description, and corresponding amount.

Detail worksheets created in federal returns appear on a page labeled OVERFLOW in View/Print mode. State return worksheets appear on a page labeled XXOVFLOW (where XX = state abbreviation).

A bright green field indicates "the field has been flagged for review" (also called an unverified field). Fields may appear green if brought forward from prior year or flagged by a conversion program.

Red and bright green are system defaults but can be customized in Setup > Colors.

## MFC or "Multi-form code"

The multi-form code box directs income or deductions from one screen or form to another. The MFC value restarts at 1 for each screen type.

| Screen | MFC |
|--------|-----|
| First Schedule C | 1 |
| Second Schedule C | 2 |
| First E screen | 1 |
| Second E screen | 2 |
| First K1P screen | 1 |
| Second K1P screen | 2 |

### Schedule E Properties

When using MFC with rental properties on Schedule E, "the multiform code refers to the property, not the Schedule E." Each property has a separate MFC. Multiple depreciation details and Schedule E properties will generate a Form 4562 for each property.

### Schedules K-1

EF Message 1351 generates when K199 has incorrect MFC values. Each K1 screen type should have unique MFC values starting with 1. For example, with 5 K1P and 5 K1S screens, the K199 MFC would be:

| Screen | MFC on K199 |
|--------|------------|
| First K1P | 1 |
| Fifth K1P | 5 |
| First K1S | 1 |
| Fifth K1S | 5 |

## Override or Adjustment Fields

Fields allowing overrides are preceded by a red equal sign (=) and display red text. Data entered overrides program calculations.

Fields allowing adjustments are preceded by a blue plus/minus sign (+/-) and display blue text. Positive numbers increase the calculated amount; negative numbers decrease it.

## "F" Field

The "F" field excludes items from the federal return. Entering "0" prevents data from appearing on the federal return while still allowing data to flow to state returns. This is commonly used when multi-state Schedules K-1 require separate screens per state.

## ST Field

The ST dropdown indicates the state involved. When selected, information carries to that state return and may generate a state return. Choose 0 to suppress the screen from state returns.

**Note:** Some states pull information directly from the federal return, so this may not apply in all cases.

## State Overrides

When federal return information carries to state returns, you may need to suppress the item on the state data entry screen. The suppress item checkbox wording varies by form or state.

**Important:** This function may not be available for all state forms or screens.

## Invalid Character

The Modernized e-File (MeF) system allows "only single spaces, hyphens ( - ), and slashes ( / )" in most fields.

Corporate returns allow letters and numbers plus these special characters:
- Pound sign ( # )
- Ampersand ( & )
- Apostrophe ( ' )
- Parentheses ( )
- Hyphen ( - )
- Blank space

Common errors include periods after street names and commas in firm names. Calculate the return and double-click error messages to locate invalid characters.

## ZIP Codes

After entering a zip code and pressing Enter, the software auto-fills city, state, and resident state. Select the resident city and school district (if applicable).

Drake Tax uses a ZIP Code database to auto-fill based on US resources, typically selecting the first/most common option. If the address is in another county, manually edit the City or County field after auto-fill.
