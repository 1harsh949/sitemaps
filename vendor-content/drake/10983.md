# Drake Tax - Installation

## Overview

Drake Software customers can download and install available versions of Drake Tax through the Drake Download Center. Installing from the support website ensures you have the most current program version.

Watch the [Drake Software Installation video](https://support.drakesoftware.com/Video/drake-software-installation) for a demonstration.

## Before you Start

- Have your account number and serial number available
  - Find the account-specific serial number on the Drake Support website by logging in with SSO credentials and choosing Account > Serial Numbers
  - Contact Accounting at (828) 349-5900 if you need an unlisted serial number
- Verify that auto backups (Tools > File Maintenance > Backup) are temporarily turned off
- Be aware that other auto updating programs may interfere with installation
- Review Drake Tax - Security Information for the software login procedure
- When installing to a network, install to the root of the drive, not a subfolder
- Ensure all computers meet Drake Tax System Requirements
- To keep current client files when moving to a new computer, see Moving Existing Installation to New Computer
- If you used Drake Tax 2024, Drake Tax 2025 may have auto-installed

## Current Year Installation

1. Log into [Drake Software Support website](https://support.drakesoftware.com/AuthMenu/Download?softwareCategory=DrakeTax) using SSO credentials
2. Choose Downloads > Drake Tax
3. Select the desired tax year from the dropdown and click Download
4. During download, respond to security warnings to continue. Choose Run to install immediately or Save to install later
5. When the installation popup appears, select Yes to begin
6. Click Install Drake Tax 2025
7. Read and accept the Drake Software License Agreement, then click Next
8. Select the installation location (prior year location is noted if available), then click Next
9. Verify installation details and click Next
10. Select states to install (optional in January; unavailable in December), then click Next
11. For licensed versions, enter your Account number and Serial number, then click Next
12. Review IRS Security Summit information pages, then click Install on the Summary page
13. If prompted, follow the Drake Tax Prerequisites Setup Wizard to install needed peripheral programs
14. Click Finished when installation completes
15. Review the What's New document or watch the What's New video before clicking Exit

**Note:** On first launch of Drake Tax 2025, you'll be prompted to agree to the license and set up administrator login. Your settings will update from Drake Tax 2024.

## Prior Years

Prior years of Drake Tax are available from the Drake Software Support website. Installation steps may vary by year. After selecting your program, follow the installation wizard.

**Tip:** For returns from years no longer available online, visit the IRS website for fillable PDFs at https://www.irs.gov/forms-pubs/prior-year
