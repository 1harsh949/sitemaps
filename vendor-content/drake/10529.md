# Drake Tax - e-Filing a Return

## Years Supported

The IRS supports e-file of the current year and two prior years through the MeF system. During 2025, you can e-file 2025, 2024, or 2023 returns. All other prior years require paper filing.

Filing compliance is based on transmission time, not IRS receipt time. The deadline is "midnight local time on the date the return is due." Once transmitted, returns cannot be stopped or recalled. Drake Software recommends e-filing several hours before the deadline.

To transmit prior year state returns, Drake Software must support that return type and the state must accept them for that year.

Returns are subject to scheduled maintenance outages. Generally, Form 7004 must be filed by the applicable return's due date—an untimely filing cannot be cured by e-filing.

## e-File Steps

For main federal forms (1040, 1120, 1120-S, 1065, 990), follow four steps:

**1. Confirm return is complete and eligible**

- Install all updates
- View the return
- Clear red messages
- Calculate and verify green checks on desired forms

**2. Select returns via EF > Select Returns for EF**

- A report generates showing selected returns (not yet transmitted)
- If changes are made after selection, the return is removed from the queue and must be re-selected

**3. Transmit via EF > Transmit/Receive**

- Verify only intended returns display
- Note that transmitted returns cannot be stopped or recalled
- Remove returns by clicking Review if needed
- Click Send/Receive when ready
- A transmission report generates for record-keeping

**4. Process acknowledgments via EF > Process Acks**

- Shows pending acknowledgment reports and pulls waiting IRS/state acks
