# Drake Tax - Clearing EF Messages

## Overview

In data entry, click the Calculate button on the toolbar (or press Ctrl + C) to access the Calculation Results screen. The EF Status column displays information about each return type's e-filing status:

| Indicator | EF Eligibility |
|-----------|---|
| Green Check | Product is eligible and has no EF Messages |
| Red X | Product is not eligible for e-file due to EF Messages |
| Accepted | Product already transmitted with "A" acknowledgment |
| Suppressed | Ready for e-file but suppressed via EF screen or Setup options |
| Paper-Filed | Suppress checkbox selected on EF screen or Setup |
| Not Selected | Ready for e-file but not selected on EF screen |
| Not Available | e-File not enabled by state or IRS for specific product |

**To resolve EF messages:**

- For blue text messages: Right-click and select "View Full Text of EF Message" to read the full script. Double-click to be redirected to the screen requiring correction, where the field is highlighted in blue.

- For black text messages: Right-click and select "View Full Text of EF Message" to read the complete script.

If ineligible for e-filing with no messages displayed, click Continue to return to data entry, then click View (or press Ctrl + V).

The MESSAGES pages display with a red background for federal and state sections. Clear federal EF Messages first, then state messages.

**Note:** Review NOTES pages as they may contain important information, though they don't prevent e-filing.

## Notes

- If filing an extension, MESSAGES pages don't require clearing, but any ETD_MSG pages must be cleared first.

- If a return is pending, an EF Message prevents e-file. Check acknowledgments before re-transmitting. Relevant message numbers: 3300, 3301, 3302, 3303, 3304.

- For FinCEN 114 filings, the message page is titled FBAR Messages and must be cleared before transmission.

## Blank Message Page

If a MESSAGES page appears but is blank:

1. Return to data entry (click Data Entry at top left).
2. Press Ctrl + Shift + R.
3. Select Repair in the pop-up window.
4. Select Yes to save changes.
5. Select Exit.
6. Return to View/Print mode to verify the blank page is gone.

If the blank message persists, contact Drake Support at (828) 524-8020.
