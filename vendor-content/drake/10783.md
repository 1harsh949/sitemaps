# Drake Tax - Search EF Database, Common Acks, and Rejection Codes

## Overview

After receiving acknowledgments, you must process them within the software via EF > Process Acks to incorporate them into return records. When an acknowledgment is processed, it becomes part of the EF record for that social security number and displays in your local EF database. To view acknowledgments, navigate to EF > Search EF Database, enter the SSN in the upper-left box, and click Go.

A separate set of EF data exists for each transmission. For additional details, refer to Drake Tax - Return Status: Checking Acknowledgments.

Watch the EF Database video for a demonstration.

## Acknowledgment Codes

Acknowledgments displayed in the Search EF database screen may include:

- **A ack** - Federal or State accepted
- **a ack** - Extension accepted (PCM only)
- **B ack** - Bad transmission
- **D ack** - Duplicate. This return is a duplicate of an accepted return - do not resend.
- **E ack** - Return Imperfect return election
- **P ack** - Pending / Processing
- **R ack** - Rejected; click on reject number to see explanation.
- **S ack** - Federal pending or rejected, return paper-filed with bank product info included
- **T ack** - Test transmission (does not go to the IRS)
- **X ack** - Bad transmission to Drake. Resend return, contact Drake Support if the problem persists.

Rejects appear under the Reject Information section on the right side. Click underlined codes in the Reject Code column to display explanations. Review reject code explanations on the F4 - Reject Code Lookup tab.

An online database is accessible by clicking F10 while on EF > Search EF Database for running various reports and detailed information.

## Ack Code Details

### B Ack

This indicates an error in the actual file data caught before sending to the IRS. Often caused by a failed software update. Locate and correct the error, then retransmit.

If you offer bank products, B acks may indicate that the add-on fee entered on your bank application does not match the one in Setup > Firm.

B Ack 7206 Format Error results from a serial number in the transmission record not matching the one on file for that EFIN. This could stem from incorrect serial number entry during installation or subsequent editing.

### E Ack

This indicates the Imperfect Return Indicator was selected for this return and it has been processed and accepted.

### P Ack

A P ACK indicates you have transmitted and Drake has received a live return, which will be forwarded to the IRS or state DOR.

**Tip:** When a return is in pending status, it has been transmitted and awaits acknowledgment (acceptance or rejection) from the IRS or state. During high-volume periods, pending status may last longer than usual. A return is considered timely filed as long as successfully transmitted by midnight local time on the due date, even if acknowledgment arrives later.

Go to EF > Process Acks to retrieve any available acks.

### T Ack

This indicates you have transmitted and Drake has received a test return.

### S Ack

If a return is pending or rejected and cannot be fixed, retransmitted, and accepted electronically, you may choose to paper-file. If mailed with bank product direct deposit information, it will receive an S ack when the IRS processes the paper-filed return.

The return must have been e-filed and received either a pending or rejected ack before a bank product can be processed from a paper-filed return.

The S Ack allows you to print ERC/RT type checks on refunds in-office while still receiving direct deposit for preparer fees.

An S ack can also appear briefly when a bank ack posts before the IRS ack - the S will convert to A when the IRS ack posts.

### X Ack

This means the file is a bad transmission and must be re-transmitted. If this problem persists, contact Drake Support.

## Reject Code Lookup

To look up a reject code, go to EF > Search EF Database and select the F4 - Reject Code Lookup tab. Enter the reject code in the Reject Code box, then click Go next to the return type selections.

This function is available even without returns with this reject in your database.

**Note:** If a return is rejected, you must correct it during the perfection period for it to be considered timely filed. See Drake Tax - Top Federal Rejects for a list of common rejects and resolutions.

The perfection period is not an extension. If you do not make a timely filing, there is no perfection period. DRKPARSE and Drake B-ack errors do not qualify for the perfection period.

### IRS Reject Code

Select 1040 and then FED from the Category drop list. Enter the reject code in the Reject Code box and click Go. The IRS explanation displays in the window below.

### State Reject Code

Select 1040, then select the state from the Category drop list. Enter the reject code in the Reject Code box and click Go. The state explanation displays in the window below.

### Bank Codes

Loan Status Codes - select this to view loan status codes and descriptions (no Category selection). See Drake Tax - Bank Status Codes for details.

## e-File Status Feature

The e-File Status feature expands the existing e-File Database, consolidating e-file tasks while allowing you to check firm e-file records using the familiar EF Database (EF > Search EF Database). Access requires sufficient Drake Tax security permissions.

### Check Status

Click e-File Status > Check e-File Status to check for and process new acknowledgments from recently e-filed returns. If new acknowledgments from Drake Software need processing, a red indicator appears on the e-File Status icon. All information received automatically adds to the EF Database, accessible from Drake Tax and the Drake Software Support website > Reports > E-file Status Lookup.

### Rehang Acks from Drake Server

Click e-File Status > Rehang Acks from Drake Server to rehang your own acknowledgments and ensure acks in Drake Tax match those on the Drake server.

**Process:**

1. Click the e-File Status icon on the Drake Tax Home screen.
2. Select Rehang Acks from Drake Server.
3. On the Client Selection window, select the individual or business taxpayer for whom acks need review.
4. A grid shows e-filed returns for the selected taxpayer. Compare the acknowledgment status on your local installation (Your Status) with the Drake server status (Drake Status). If "Out of Sync" appears under the Status column, click Request Ack to synchronize information between local and Drake database.
5. A message displays indicating the request is processing.
6. You may wait for completion or Close the dialog box and work on something else while acks sync.
   - If you wait, the Process Acks window opens automatically after completion. Review and print acks as needed.
   - If you exit by clicking Close, manually go to EF > Process Acks to review results.

**Important:** Bank Acks are not rehung during this process. For assistance with bank acks or EF Rebuild due to computer crash, contact Drake Support at (828) 524-8020.
