# Return Troubleshooting - Tips and Tricks

## LinkBacks

Review data sources by right-clicking on any field in View/Print mode and selecting "Review Input Sources (LinkBacks)." This feature shows where values, checkmarks, or entries originate from across screens and worksheets.

Double-clicking on a screen name returns you to data entry mode for that specific screen, allowing you to review or modify entries. This is particularly useful for locating data entry points for checkboxes or lines without current values.

**Example use case:** To find where to mark that a spouse is blind on Form 1040:

1. Go to View/Print mode and right-click the blank checkbox
2. Choose "Review Input Sources (LinkBacks)"
3. Double-click the indicated screen
4. The appropriate checkbox appears highlighted for selection

This feature is available for most fields in View/Print mode.

## DoubleCheck

Enable DoubleCheck in View/Print mode to flag and clear flags without entering data entry mode.

**To enable:**

- Right-click any line in View/Print mode
- Click "Enable left-click for DoubleCheck items"

**To use:**

- Left-click a line to place a green check mark
- Click again to flag the line (red flag)
- Click a third time to clear the flag

This helps troubleshoot how data entry changes affect the return. If a verified line (green check) changes after a data entry modification, it converts to a red flag, showing "Value Changed—Previous Entry: ____."

## Searching

In data entry mode, search for screen names, form names, and numbers by typing and pressing Enter. Matching amounts display across all screens, helping identify duplicate or unexplained entries.

## Data Entry Field Help

Field help text provides limits set by the IRS or state Department of Revenue. This explains why View/Print amounts differ from entered values. For example, 1099-R Insurance Premiums has a maximum exclusion amount that limits reported figures.

## Notes

Check the Notes section in View/Print mode for year-specific form changes and known calculation modifications, useful for understanding differences from prior years.

## Line Descriptions and Form Instructions

Review line descriptions and form instructions for worksheet references and calculation guidelines. IRS and Drake-generated worksheets help explain calculations by tracing amounts backward through the process.

## Archive or Tax Planner Functions

Create an archive or use Tax Planner mode to perform "what-if" calculations and test election effects without affecting the completed return. You can even delete screens in Tax Planner mode to observe impacts.
